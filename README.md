# Public Speaking sebagai Kunci Pengembangan SDM

Website artikel berbasis HTML/CSS untuk diunggah ke GitHub Pages.

## File
- `index.html` — halaman utama website.
- `assets/` — folder aset gambar jika ingin menambahkan gambar sendiri.

## Cara upload ke GitHub
1. Buat repository baru di GitHub.
2. Upload `index.html` dan folder `assets`.
3. Buka **Settings → Pages**.
4. Pada Source pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/root`, lalu Save.
6. GitHub akan memberikan alamat GitHub Pages setelah proses deployment selesai.

Materi artikel disusun berdasarkan file sumber yang diberikan.
